# 🌀 Harmonic Text Mirror

The **Harmonic Text Mirror** is a system that classifies words into three harmonic categories (**A**, **B**, and **C**) based on the digital root of their letter values.

## 🚀 Features
- Supports English and Hebrew character mappings
- Handles punctuation and case-insensitivity
- Provides real-time classification and visual distribution charts
- Built with Python and Streamlit
