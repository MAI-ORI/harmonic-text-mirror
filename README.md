# Harmonic Text Mapping System

The **Harmonic Text Mapping System** is a symbolic and computational framework that translates written language into harmonic sequences based on digital roots, letter-to-number mappings, and triadic classification. It is designed for introspective analysis, emotional tone feedback, and integration with decentralized token economies.

---

## 🚀 Features

- **Multilingual Support**: Handles any language using Unicode and custom alphabet mappings.
- **Symbolic Classification**: Categorizes words into three harmonic types:
  - **A (Alpha)**: Prime-resonant, initiating, structured
  - **B (Beta)**: Composite-resonant, reflective, emotional
  - **C (Gamma)**: Neutral, bridging, stabilizing
- **Interactive Web App**: Built with Streamlit for real-time text analysis and visualization.
- **Crypto Integration**: Supports tokenized rewards for coherence and harmonic balance.

---

## 🛠️ Project Structure

- `app.py`: Streamlit web application interface.
- `harmonic_text_mapping.py`: Core logic for word classification and digital root calculation.
- `requirements.txt`: Python dependencies.
- `README.md`: Project documentation.
- `.gitignore`: Files to exclude from version control.

🌐 Deployment
This app is ready to be deployed on Streamlit Sharing:

Push this repository to your GitHub account.
Go to share.streamlit.io and log in with GitHub.
Click New app, select this repository, and set the main file path to app.py.
Click Deploy!
